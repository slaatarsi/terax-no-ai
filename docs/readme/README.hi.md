# Terax

**फ़ोल्डर एक्सप्लोरर और Git ट्रैकिंग वाला हल्का टर्मिनल। कोई अंतर्निहित AI एजेंट नहीं।**

यह संस्करण [crynta/terax-ai](https://github.com/crynta/terax-ai) का संशोधित फ़ोर्क है और [slaatarsi/terax-no-ai](https://github.com/slaatarsi/terax-no-ai) में अलग से बनाए रखा जाता है। मूल परियोजना का श्रेय Crynta और अपस्ट्रीम योगदानकर्ताओं को जाता है।

## सुविधाएँ

- टैब, विभाजित पैनल, खोज और शेल एकीकरण वाला नेटिव टर्मिनल।
- खोज, फ़ाइल प्रबंधन और लाइव अपडेट वाला फ़ोल्डर एक्सप्लोरर।
- Git स्थिति, diff, staging, commit, push और ग्राफ़ के साथ इतिहास।
- एडिटर, वैकल्पिक भाषा सर्वर, प्रीव्यू और थीम सहायक उपकरण के रूप में मौजूद हैं।

अंतर्निहित AI चैट, एजेंट, AI प्रदाता, AI ऑटोकम्प्लीशन या वॉइस इनपुट नहीं हैं। CLI प्रोग्राम मैन्युअल रूप से चलाए जा सकते हैं। पुराने AI डेटा और बाहरी हुक लोड नहीं किए जाते और न ही अपने आप हटाए जाते हैं।

## सोर्स से बिल्ड करें

Rust stable, Node 22+, pnpm और अपने प्लेटफ़ॉर्म की [Tauri आवश्यकताएँ](https://tauri.app/start/prerequisites/) चाहिए।

```bash
git clone https://github.com/slaatarsi/terax-no-ai.git
cd terax-no-ai
pnpm install
pnpm tauri dev
# प्रोडक्शन पैकेज:
pnpm tauri build
```

**चेतावनी:** अपडेट कॉन्फ़िगरेशन अभी भी अपस्ट्रीम रिलीज़ की ओर इशारा करता है। अपडेट स्वीकार करने से यह फ़ोर्क मूल संस्करण से बदल सकता है। अपस्ट्रीम इंस्टॉलर और पैकेज इस AI-रहित संस्करण के समान नहीं हैं। फ़ोर्क के लिए अलग कोड साइनिंग की गारंटी नहीं है।
