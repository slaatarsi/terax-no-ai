# Terax

**Лёгкий терминал с проводником папок и отслеживанием изменений Git. Без встроенных ИИ-агентов.**

Это изменённый форк [crynta/terax-ai](https://github.com/crynta/terax-ai), который поддерживается отдельно в [slaatarsi/terax-no-ai](https://github.com/slaatarsi/terax-no-ai). Авторы исходного проекта: Crynta и участники upstream.

## Возможности

- Нативный терминал с вкладками, разделением панелей, поиском и интеграцией оболочки.
- Проводник папок с поиском, управлением файлами и обновлениями в реальном времени.
- Статус Git, различия, подготовка изменений, коммиты, push и граф истории.
- Редактор, необязательные языковые серверы, предпросмотр и темы сохранены как вспомогательные инструменты.

Нет встроенного ИИ-чата, агентов, ИИ-провайдеров, ИИ-автодополнения и голосового ввода. CLI-программы можно запускать вручную. Старые данные ИИ и внешние хуки не загружаются и не удаляются автоматически.

## Сборка

Нужны стабильный Rust, Node 22+, pnpm и [зависимости Tauri](https://tauri.app/start/prerequisites/).

```bash
git clone https://github.com/slaatarsi/terax-no-ai.git
cd terax-no-ai
pnpm install
pnpm tauri dev
# Пакет для распространения:
pnpm tauri build
```

**Внимание:** конфигурация обновлений всё ещё указывает на upstream-релизы. Такое обновление может заменить форк исходной версией. Установщики и пакеты upstream не следует считать этой версией без ИИ. Подпись сборок именно этого форка не гарантируется.
